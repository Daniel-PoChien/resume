# Po-Chien Cheng — Résumé & CV

A responsive, accessible résumé website, built with plain HTML and CSS and hosted on GitHub Pages.

**Website:** https://daniel-pochien.github.io/resume/

## Update

- Edit `index.html` to update résumé content.
- Edit `styles.css` to adjust the design.
- Replace `assets/Po-Chien-Cheng-Resume.pdf` to update the downloadable résumé.
- Push changes to `main`; GitHub Pages publishes from the repository root.

## Preview locally

Run `python3 -m http.server 8000` and open http://localhost:8000.

No build step, dependencies, analytics, or external fonts.
